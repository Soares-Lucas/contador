# Relógio de Evento

Aplicação de cronômetro e relógio de evento desenvolvida em React com TypeScript e Vite.

## Funcionalidades

- Contagem de tempo em dias, horas, minutos, segundos e milissegundos.
- Controles de Iniciar (`Iniciar`), Pausar (`Pausar`), Continuar (`Continuar`) e Resetar (`Resetar`).
- Interface estilizada com a fonte Orbitron e tema idêntico ao projeto original.

## Scripts

- `npm run dev` - Inicia o servidor de desenvolvimento na porta 3000
- `npm run build` - Compila o projeto com TypeScript e Vite
- `npm run preview` - Pré-visualiza a build de produção
